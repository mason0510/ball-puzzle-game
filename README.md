# 弹球寻路 (Ball Puzzle Game)

一个基于物理引擎的益智游戏，玩家需要通过放置弹力墙来引导小球到达目标位置。

## ✨ 特性

- 🎮 **物理引擎驱动** - 真实的弹球物理效果
- 🎯 **关卡系统** - 多个精心设计的关卡，难度递增
- 🏗️ **创意解谜** - 通过放置弹力墙来规划小球路径
- 📱 **响应式设计** - 支持桌面和移动设备
- 🎨 **精美UI** - 现代化的界面设计，流畅的动画效果
- ⚡ **纯前端实现** - 无需后端，打开即玩

## 🎮 游戏玩法

1. **目标**：引导蓝色小球到达绿色目标区域
2. **操作**：
   - 点击游戏区域放置弹力墙
   - 放置完成后点击"发射"按钮
   - 小球会从起点发射，遇到弹力墙会反弹
3. **获胜条件**：小球进入目标区域并停留
4. **挑战**：
   - 每关有弹力墙数量限制
   - 需要精心规划路径
   - 考虑物理反弹效果

## 🚀 快速开始

### 在线体验

直接用浏览器打开 `index.html` 文件即可开始游戏。

### 本地部署

```bash
# 克隆仓库
git clone https://github.com/mason0510/ball-puzzle-game.git

# 进入目录
cd ball-puzzle-game

# 用浏览器打开
open index.html  # macOS
# 或
start index.html  # Windows
# 或直接双击 index.html 文件
```

### 部署到服务器

项目为纯静态HTML文件，可直接部署到任何静态服务器：

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- 或任何支持静态文件的服务器

## 🛠️ 技术栈

- **纯HTML5** - 无需构建工具
- **Canvas API** - 游戏渲染
- **原生JavaScript** - 游戏逻辑和物理引擎
- **CSS3** - 界面样式和动画

## 📋 游戏关卡

- **关卡 1**: 入门级 - 学习基本操作
- **关卡 2**: 进阶 - 需要更精确的角度控制
- **关卡 3**: 困难 - 复杂的路径规划
- 更多关卡持续更新中...
