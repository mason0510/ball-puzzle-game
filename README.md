# 弹球寻路 (Ball Puzzle Game)

一个基于物理引擎的益智游戏，玩家需要通过放置弹力墙来引导小球到达目标位置。

## ✨ 特性

- 🎮 **物理引擎驱动** - 真实的弹球物理效果（重力、碰撞、弹跳）
- 🎯 **5个精心设计的关卡** - 从入门到终极挑战，难度递增
- 🏗️ **创意解谜** - 使用挡板和弹簧引导小球到达目标
- 🎵 **动感音乐系统** - 电子风格背景音乐 + 丰富的音效
- 🔊 **完整音效** - 放置工具、发射、弹跳、获胜等多种音效
- 📱 **响应式设计** - 支持桌面和移动设备
- 🎨 **精美UI** - 现代化渐变设计，流畅的动画效果
- ⚡ **纯前端实现** - 无需后端，打开即玩
- 🎛️ **音乐开关** - 一键关闭背景音乐

## 🎮 游戏玩法

1. **目标**：引导蓝色小球到达绿色目标区域
2. **操作**：
   - 点击"挡板"或"弹簧"按钮选择工具
   - 在游戏区域点击放置工具
   - 右键点击已放置的工具可删除
   - 放置完成后点击"发射"按钮
   - 小球会从起点发射，遇到挡板会反弹，遇到弹簧会加速
3. **获胜条件**：小球进入目标区域并停留
4. **挑战**：
   - 每关有工具数量限制（8-20个）
   - 需要精心规划路径
   - 考虑重力、速度衰减、弹跳角度等物理效果

## 🚀 快速开始

### 在线体验

**在线演示**: [http://111.229.63.121/ball-puzzle.html](http://111.229.63.121/ball-puzzle.html)

或者直接用浏览器打开 `index.html` 文件即可开始游戏。

### 本地部署

```bash
# 克隆仓库
git clone https://github.com/mason0510/ball-puzzle-game.git

# 进入目录
cd ball-puzzle-game

# 用浏览器打开
open index.html  # macOS
# 或
start index.html  # Windows
# 或直接双击 index.html 文件
```

### 部署到服务器

项目为纯静态HTML文件，可直接部署到任何静态服务器：

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- 或任何支持静态文件的服务器
